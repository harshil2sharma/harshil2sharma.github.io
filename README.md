# harshil2sharma.github.io

Personal website for Harshil Sharma — Data Scientist & AI Engineer.

Built with [Quarto](https://quarto.org). Source lives at the top level (`index.qmd`, `about.qmd`, `blog.qmd`, `posts/`); the rendered site is published from `docs/` via GitHub Pages.

## Local development

```
quarto preview   # live-reloading local preview
quarto render    # render into docs/
```

Live at <https://harshil2sharma.github.io>.
